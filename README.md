# لوحة اللطف والاحترام | اليوم العالمي لمكافحة التنمر 🌷

صفحة تفاعلية بأسلوب **Padlet** مصممة خصيصاً لمشاركات الطالبات في اليوم العالمي لمكافحة التنمر، تحت إشراف الموجهة الطلابية **أ. عفاف شامي**.

---

### ✨ المميزات المتوفرة في الصفحة:
1. **تصميم شبيه بـ Padlet الحقيقي**:
   - بطاقات ملونة بنمط الملاحظات اللاصقة (Sticky Notes) مع تأثير الشريط اللاصق وظلال عصرية.
   - رسالة ترحيبية وتوجيهية مثبتة في الأعلى باسم الموجهة الطلابية **عفاف شامي**.

2. **خيارات متنوعة للمشاركات**:
   - 💬 **كلمات هادفة**: مشاركة تعبيرية وكلمات محفزة.
   - 🎨 **رسومات وإبداعات**: إمكانية رفع صورة أو رسمة مع عارض صور مكبّر (Lightbox).
   - 💡 **عبارات توعوية**: نصائح واقتباسات لمناهضة التنمر ونشر اللطف.

3. **تفاعلية كاملة**:
   - زر إضافة مشاركة مع إمكانية اختيار لون البطاقة.
   - زر الإعجاب والتفاعل بالقلوب 💖 مع مؤثر صوتي واحتفالي (Confetti).
   - تصفية المشاركات حسب النوع والبحث المباشر باسم الطالبة أو نص المشاركة.
   - حفظ تلقائي للمشاركات في المتصفح (`localStorage`).
   - جاهزة للطباعة أو التصدير كملف PDF وحفظها في أرشيف النشاط المدرسي.

---

### 🚀 كيفية التشغيل والمشاركة:
- **تشغيل محلي**: انقري نقراً مزدوجاً على ملف `index.html` ليفتح فوراً في أي متصفح (Edge، Chrome، Firefox).
- **المشاركة مع الطالبات**: يمكن رفع هذا الملف البسيط على أي استضافة مجانية مثل (GitHub Pages، Netlify، Vercel) أو وضعه على منصة مدرستي / ون درايف ومشاركة الرابط المباشر مع الطالبات.
